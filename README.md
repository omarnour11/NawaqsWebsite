# موقع قائمة الوصول المبكر — منصة نواقص (Nawaqss Wishlist)

صفحة هبوط احترافية وموقع متكامل لجمع بيانات الراغبين بالانضمام للخدمة مبني وفق هوية **Nawaqss Brand Kit v3** وجاهز للربط بالدومين والنشر على سيرفر الإنتاج فوراً.

---

## 🚀 التحديثات الجوهرية (Production Fixes)
1. **الاسم الرسمي المعتمد:** تم اعتماد **Nawaqss** و **نواقص** في كافة النصوص والبيانات والملفات.
2. **تبسيط النموذج وإلغاء حقل الدواء:** تم إلغاء حقل إدخال الدواء المطلوب نهائياً لتسهيل التسجيل وتسريع جمع البيانات (اسم، موبايل، إيميل اختياري، محافظة، حي، طريقة تواصل، ملاحظات).
3. **حماية أمنية للوحة الإدارة وتحميل الـ CSV:**
   - تم **حذف أي أزرار أو كلمات سر أو نوافذ إدارية من الواجهة العامة للمستخدمين نهائياً**.
   - إنشاء صفحة إدارة مستقلة ومحمية بالكامل: `/admin` أو `/admin.html`.
   - فحص المفتاح السري (`ADMIN_SECRET_KEY`) يتم في الـ Server، ولا يتم كشفه في كود الجافاسكربت.
   - منع تحميل ملف الـ CSV إلا عبر المفتاح السري المصرح به.
4. **حل مشكلة خطأ تحميل ملف الـ CSV:**
   - إصلاح مسار التصدير وتفعيل التنزيل المباشر مع دعم `UTF-8 BOM` ليفتح ملف الإكسيل باللغة العربية السليمة فوراً.

---

## 📋 البيانات المخزنة في ملف الـ CSV
يتم تخزين كل تسجيل في `wishlist_leads.csv` بالأعمدة التالية:
- **كود الطلب** (مثل: `NWQ-WL-8491`)
- **تاريخ التسجيل (UTC)**
- **الصفة** (مريض / صيدلية)
- **الاسم بالكامل**
- **رقم الموبايل** (معتمد مصري: 010, 011, 012, 015)
- **البريد الإلكتروني** (اختياري)
- **المحافظة** (من الـ 27 محافظة)
- **المدينة أو المنطقة**
- **طريقة التواصل المفضلة** (واتساب / مكالمة / إيميل)
- **ملاحظات إضافية**
- **IP العميل**

## 🔐 لوحة الإدارة وتحميل الـ CSV (Admin Portal)

### للدخول للوحة الإدارة:
افتح في المتصفح:
`http://your-domain.com/admin` أو `http://localhost:8080/admin`

- سيُطلب منك إدخال **المفتاح السري (Admin Secret Key)**.
- المفتاح يُحدد عبر متغير البيئة `ADMIN_SECRET_KEY` (لا يوجد مفتاح افتراضي، ولا تضع المفتاح الحقيقي داخل ملفات المستودع).
- بعد إدخال المفتاح ستظهر لك الإحصائيات الفورية وجدول المسجلين، مع زر مباشر لتحميل ملف الإكسيل `nawaqss_wishlist_leads.csv`.

### رابط التحميل المباشر السري (للاستخدام التلقائي):
```
http://your-domain.com/api/admin/export?key=YOUR_ADMIN_SECRET_KEY
```

## 🛠️ خيارات التشغيل والنشر على السيرفر (Deployment)

### 1. التشغيل المباشر عبر Node.js (موصى به للإنتاج):
```bash
cd wishlist-website
export PORT=80
export ADMIN_SECRET_KEY="YourStrongSecretKeyHere"
node server.js
```
أو عبر **PM2** لضمان استمرار عمله في الخلفية:
```bash
npm install -g pm2
pm2 start server.js --name "nawaqss-wishlist"
pm2 save
```

### 2. التشغيل عبر Python:
```bash
cd wishlist-website
export PORT=80
export ADMIN_SECRET_KEY="YourStrongSecretKeyHere"
python3 server.py
```

### 3. التشغيل عبر Docker و Docker Compose:
```bash
cd wishlist-website
docker compose up -d --build
```

### 4. الربط مع Nginx ودومين حقيقي:
انسخ ملف `nginx.conf.example` إلى `/etc/nginx/sites-available/` وفعّله، ثم استخرج شهادة SSL مجانية عبر Certbot:
```bash
sudo certbot --nginx -d your-domain.com
```
